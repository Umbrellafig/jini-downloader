# 사용 방법

1. 앱 실행 후 최초 한 번 필수 도구를 설치합니다.
2. URL을 한 줄에 하나씩 입력합니다. 종류를 고를 필요 없이 분석하기를 누릅니다.
3. 분석 후 제목·썸네일·품질·용량을 확인합니다.
4. 체크박스로 받을 파일을 선택합니다. 동영상은 저장 품질 메뉴에서 선택합니다.
5. 저장 폴더를 선택하고 선택 다운로드 또는 전체 다운로드를 누릅니다.

영상과 음성이 별도 파일인 경우 각각의 진행바를 표시합니다. 다운로드 완료 후 병합·확인 단계가 이어질 수 있습니다. 각 스트림의 100%가 최종 파일의 저장 완료를 의미하지는 않습니다. '완료' 표시를 확인하세요.

서버가 크기를 제공하지 않는 경우 진행 중에도 정확한 퍼센트와 남은 시간을 알 수 없습니다. 그때는 받은 용량과 속도를 표시합니다. 추정값은 '약'으로 구분합니다.

파일이름과 포맷은 다운로드 전에 확인할 수 있지만, 파일명에 저장 불가능한 문자 처리나 충돌 방지 번호 추가로 최종 이름이 조금 바뀔 수 있습니다. MKV는 영상·음성을 담는 컨테이너이며 그 자체가 추가 압축을 의미하지 않습니다.

사진·갤러리는 최대 200개 항목을 표시합니다. 너무 큰 이미지 또는 사전 정보가 없는 파일은 썸네일 대신 아이콘을 표시할 수 있습니다. DRM·로그인 제한 콘텐츠는 지원하지 않습니다.

문제가 생기면 상세 로그를 확인하세요. 사이트 오류, 로그인 요구, 봇 차단 및 사용할 수 없게 된 포맷은 다른 화질로 몰래 바꾸지 않고 실패로 표시됩니다. 다시 분석해 현재 제공되는 포맷을 선택해 주세요.
