# 사용 방법

1. 앱 실행 후 최초 한 번 필수 도구를 설치합니다.
2. URL을 한 줄에 하나씩 입력합니다. 종류를 고를 필요 없이 분석하기를 누릅니다. 링크를 복사한 뒤 앱으로 돌아오면 ‘붙여넣고 분석’을 제안합니다(설정 → 일반에서 끌 수 있음). 붙여넣기는 복사한 글에서 링크만 골라 넣습니다. 링크는 앱 창이나 Dock 아이콘에 끌어다 놓아도 되고, 다른 앱에서 링크나 글을 선택한 뒤 오른쪽 클릭 → 서비스 → ‘지니 다운로더로 분석’으로 보낼 수도 있습니다. 자동화 도구에서는 `jinidownloader://open?url=<인코딩한 주소>`(여러 개면 url을 반복)로 앱에 링크를 넘길 수 있습니다. 어떤 방법이든 분석만 하고, 다운로드는 직접 고른 뒤 시작합니다.
재생목록 링크를 넣으면 목록의 영상(최대 200개)을 표에 펼칩니다. 영상마다 미리 분석하지 않으므로 빠르게 나오며, 품질은 ‘가장 좋은 품질 · 받을 때 결정’ 또는 음성만을 고를 수 있습니다. 받을 영상을 체크한 뒤 선택 다운로드를 누르세요. ‘바로 받기’를 켜 두어도 재생목록 전체를 한꺼번에 받지는 않습니다.

3. 분석 후 종류 탭(전체·이미지·동영상·기타)으로 거르고, 표 머리의 파일명·종류·포맷·품질·용량을 눌러 정렬합니다. 한 번 누르면 오름차순, 다시 누르면 내림차순, 한 번 더 누르면 찾은 순서로 돌아갑니다. 값을 모르는 파일은 항상 맨 뒤에 둡니다. 썸네일을 누르면 크게 봅니다.
4. 체크박스로 받을 파일을 선택합니다. 모두 선택·해제는 지금 보이는 종류에만 적용됩니다. 동영상은 품질 메뉴에서 선택합니다.
5. 선택 다운로드 또는 전체 다운로드를 누릅니다. 설정 → 일반의 ‘분석이 끝나면 바로 받기’를 켜면 분석 직후 동영상(없으면 열린 게시물이나 사진 모음의 파일)을 가장 좋은 품질로 바로 받습니다. 페이지 장식 이미지는 받지 않으며, 받을 대상이 없으면 직접 고르도록 알려 줍니다. 시작한 파일은 찾은 파일 목록에서 빠져 아래 다운로드 칸에 대기·진행·완료·실패 순서대로 쌓입니다. 취소로 시작하지 못한 파일은 목록으로 돌아갑니다. 완료 항목 정리는 저장된 파일을 지우지 않고 목록에서만 뺍니다. 기본 저장 위치는 다운로드 폴더이며, 설정(⌘,)에서 바꾸거나 되돌릴 수 있습니다.

게시물 하나를 창으로 띄우는 링크는 뒤에 깔린 페이지 전체가 아니라 열린 게시물 안의 이미지·동영상만 '열린 게시물'로 보여 줍니다. 페이지 전체를 받으려면 게시물이 열리지 않는 주소를 넣으세요. 이미지 변환 서버를 거쳐 표시된 이미지는 원본 주소를 찾아 원본 파일을 저장하고, 작은 사본은 미리보기로만 씁니다.

영상과 음성을 따로 받는 경우에도 진행바는 하나로 합쳐 보여 줍니다. 음성을 받기 전까지 전체 용량은 미리보기의 예상 용량('약')으로 계산합니다. 다운로드 후 병합·MP4 저장 단계가 이어질 수 있으므로 진행바 100%가 저장 완료를 뜻하지는 않습니다. '완료' 표시를 확인하세요. 다운로드 중에는 Dock 아이콘에 남은 파일 수가 표시되고, 다른 앱을 쓰는 동안 끝나면 알림을 보냅니다(처음 한 번 알림 허용을 묻고, 설정 → 일반에서 끌 수 있음).

서버가 크기를 제공하지 않는 경우 진행 중에도 정확한 퍼센트와 남은 시간을 알 수 없습니다. 그때는 받은 용량과 속도를 표시합니다. 추정값은 '약'으로 구분합니다.

파일이름과 포맷은 다운로드 전에 확인할 수 있지만, 파일명에 저장 불가능한 문자 처리나 충돌 방지 번호 추가로 최종 이름이 조금 바뀔 수 있습니다. MKV는 영상·음성을 담는 컨테이너이며 그 자체가 추가 압축을 의미하지 않습니다.

사진·갤러리는 최대 200개 항목을 표시합니다. 너무 큰 이미지 또는 사전 정보가 없는 파일은 썸네일 대신 아이콘을 표시할 수 있습니다. DRM·로그인 제한 콘텐츠는 지원하지 않습니다.

문제가 생기면 상세 로그를 확인하세요. 사이트 오류, 로그인 요구, 봇 차단 및 사용할 수 없게 된 포맷은 다른 화질로 몰래 바꾸지 않고 실패로 표시됩니다. 다시 분석해 현재 제공되는 포맷을 선택해 주세요.

받은 파일만 저장합니다. 원본 페이지·포맷·용량·저장 시각을 적은 `.download.txt` 기록 파일이 필요하면 설정(⌘,) → 고급에서 켜세요.

동영상은 QuickTime·사진 앱·아이폰에서 바로 열리는 MP4로 저장합니다. H.264·HEVC·AV1 영상은 재인코딩 없이 몇 초 안에 옮기고, VP9 등 MP4에서 재생이 어려운 영상만 Mac의 하드웨어 인코더로 H.264 변환합니다(시간이 더 걸리고 미세한 화질 차이가 생길 수 있음). 음성은 AAC·MP3면 그대로, 그 밖에는 AAC로 바꿉니다. 재인코딩을 피하려면 품질 메뉴에서 avc1(H.264) 항목을 고르세요. 소리만 필요하면 품질 메뉴에서 ‘음성만 · M4A’ 또는 ‘음성만 · MP3’를 고르세요. 가장 좋은 음성 스트림만 받아 음성 파일로 저장합니다(M4A는 원본이 AAC면 그대로 담고, MP3는 최고 품질로 변환). 사이트가 주는 영상·음성을 변환 없이 그대로 받으려면 설정(⌘,) → 고급에서 '동영상을 원본 형식(MKV)으로 저장'을 켜세요. 화질 손실이 전혀 없지만 QuickTime 등 일부 앱에서는 열리지 않습니다.

받은 파일은 이 Mac에만 기록되어, 같은 링크를 다시 분석하면 상태 열에 ‘이전에 받음’으로 표시됩니다. 서명이 바뀌는 파일 주소도 같은 파일로 알아봅니다. 기록은 ⌘Y 또는 ‘기록’ 버튼으로 열어 찾기·Finder에서 보기·다시 분석·지우기를 할 수 있고, 설정 → 고급에서 기록을 끄거나 지울 수 있습니다.
