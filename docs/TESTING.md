# 검증 범위

## 자동 테스트

`bash scripts/test.sh`에서 다음을 확인합니다.

- 선택 포맷 ID와 영상·음성 조합 유지
- 한글 제목 및 메타데이터 파싱
- 크기 누락 시 합계로 오인하지 않도록 미상 처리
- 추정 크기 및 병합 크기 표시
- 진행률, 총 크기 미상 및 완료 상태 파싱
- 갤러리 파일 필터링과 중복 제거
- URL 검증, 진행 중인 라이브 거부
- 프로세스 stdout/stderr 동시 처리 및 취소

`bash scripts/package.sh`는 네이티브 앱을 빌드하고 로컬 서명 검증 및 ZIP 무결성을 확인합니다. 로컬 서명 검증은 Apple의 배포 공증과 다릅니다.

## 실제 앱 확인

개인용 선행 버전에서 유튜브의 제목·썸네일·1080p 60fps 포맷 목록을 확인했고, 작은 공개 동영상 및 이미지의 선택 다운로드와 100% 완료 표시를 확인했습니다.

공개 배포판은 같은 기능을 유지하면서 첫 실행 엔진 설치와 별도 저장 폴더를 추가했습니다. 실행 파일은 Apple Silicon, macOS 26 환경을 대상으로 합니다.

모든 사이트, 로그인·DRM 콘텐츠, 모든 네트워크 중단 상황 및 장시간 다운로드를 보장하는 테스트는 아닙니다. 사이트 변경으로 동작이 달라질 수 있습니다.

## 1.3.0 업데이트 검증 (2026-09-10)

- macOS 26.5 SDK로 Sparkle 포함 앱 빌드 및 코드 서명 검증 성공.
- 별도 테스트 bundle ID와 localhost 피드로 1.2.9 → 1.3.0 감지, 다운로드, 앱 교체, 재시작 및 버전 변경 확인.
- 실제 ZIP의 Ed25519 서명 검증 성공, 변조한 ZIP은 검증 실패 확인.
- 기존 메타데이터/진행률/프로세스 취소 테스트 통과.
- Developer ID 서명, hardened runtime 및 timestamp 검증 성공. Apple 공증 Accepted, stapler 검증 성공, Gatekeeper 평가 `accepted / Notarized Developer ID` 확인.
- 공증 제출 ID: `6b209123-6ecd-4df1-9495-198a78fd9aaf`.
- 로컬 업데이트 검증은 임시 서명 앱으로 수행함. 공개 피드를 통한 실제 앱 교체는 별도 검증이 필요함.

## 웹페이지 이미지 탐색 — 개발 중

- 알고몬 `/n/deal`: gallery-dl의 `Unsupported URL` 및 직접 요청의 HTTP 403 `CHALLENGE_REQUIRED` 응답 재현.
- WebKit 페이지를 사용자가 열고 스크롤한 뒤 로드된 이미지 URL을 가져오는 기능 추가. 브라우저 확인 절차를 자동으로 풀거나 기존 브라우저 쿠키를 가져오지 않음.
- 이미지 URL 유효성, 중복 제거, 해상도·용량 미상 처리, 기본 선택 해제, Referer 전달 테스트 통과. 기존 코어·프로세스 테스트 및 앱 빌드 통과.
- `Tests/WebImageTests.swift`의 `--browser`는 일반 Mac 실행 환경에서 DOM 추출을 검증하는 선택적 통합 테스트. 자동 실행 환경의 WebKit 제한으로 아직 통과 여부 미확인.
- 알고몬 실제 화면의 이미지 추출 및 저장은 수동 검증 대기. 공개 릴리스는 1.3.0 유지.
