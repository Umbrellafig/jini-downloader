# 지니 다운로더 1.6.1.10

- 동영상을 QuickTime·사진 앱·아이폰에서 바로 열리는 MP4로 저장합니다. 대부분 재인코딩 없이 몇 초 만에 끝납니다. 변환 없는 원본 형식(MKV)이 필요하면 설정(⌘,) → 고급에서 켤 수 있습니다.
- 받은 파일만 저장합니다. 출처·저장 정보를 적은 `.download.txt` 기록 파일은 설정 → 고급에서 켤 때만 만듭니다.
- 분석이 훨씬 빨라졌습니다. 링크 하나당 약 20초 걸리던 분석이 약 5초로 줄었습니다. 업데이트 후 처음 실행할 때 yt-dlp(약 54MB)만 자동으로 다시 받습니다.
- 일부 사이트에서 게시물 링크의 이미지·동영상을 찾지 못하거나 다른 게시물까지 함께 표시하던 문제를 수정했습니다. 세로로 긴 이미지도 빠지지 않고 원본 크기로 저장합니다.
- 분석 결과를 파일명·종류·포맷·품질·용량 열로 정리한 표로 보여 줍니다. 열 이름을 누르면 오름차순·내림차순으로 정렬됩니다.
- 이미지·동영상·기타 탭으로 원하는 종류만 볼 수 있습니다. 작은 썸네일을 누르면 크게 볼 수 있습니다.
- 다운로드를 시작한 파일은 목록 아래 다운로드 칸으로 옮겨져, 찾은 파일 목록이 다운로드 중에 뒤섞이지 않습니다.
- 새로 설치하면 Mac의 다운로드 폴더에 저장합니다. 설정(⌘,)에서 저장 위치를 바꾸거나 되돌릴 수 있습니다. 이미 저장 폴더를 고른 경우 그대로 유지합니다.

기존 사용자는 앱의 업데이트 확인으로 설치할 수 있습니다. 신규 설치는 DMG에서 Applications 폴더로 앱을 옮겨 주세요.
