# 지니 다운로더 1.5.0

- **분석하기** 하나로 동영상·사진 게시물·웹페이지 이미지를 함께 확인
- ‘웹페이지 이미지 찾기’, ‘미리보기 분석’, 종류 선택을 제거해 흐름 단순화
- 파일을 체크해서 받는 **선택 다운로드**, 결과 목록 전체를 받는 **전체 다운로드**
- 분석 중 항목 선택, 완료 파일은 전체 다운로드에서 제외
- 페이지 동영상 주소와 이미지 자동 탐색 및 지연 로딩용 화면 크기 개선

알고몬에서 분석하기 한 번으로 19개 파일을 확인하고, 선택 다운로드 1개 및 남은 18개 전체 다운로드를 검증했습니다.
전체 다운로드는 분석 결과 목록을 대상으로 합니다. 사이트 확인·로그인 제한이나 로드되지 않은 콘텐츠는 찾지 못할 수 있습니다.

Apple Silicon(M1 이상), macOS 26 이상. 응용 프로그램 폴더에서 실행한 뒤 **업데이트 확인…**으로 설치하세요.
