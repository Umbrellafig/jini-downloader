# 지니 다운로더 1.6.0

- 최초 설치용 DMG 제공: 앱 아이콘을 Applications 폴더로 드래그해서 설치
- 다운로드·임시 위치에서 실행하면 한글 설치 안내 및 ‘응용 프로그램으로 설치’ 제공
- 기존 설치 앱은 자동으로 덮어쓰지 않고 설치된 앱 실행 안내
- 잘못된 위치에서는 자동 업데이트를 시작하지 않아 영어 업데이트 오류 예방
- README 다운로드 링크와 설치 설명을 DMG 기준으로 정리

기존 사용자는 앱의 업데이트 확인으로 설치할 수 있습니다. 신규 설치는 DMG를 열고 앱을 Applications 폴더에 옮겨 주세요.
Apple Silicon(M1 이상), macOS 26 이상용입니다.
