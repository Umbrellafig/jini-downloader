# 지니 다운로더 1.6.1.2

- 분석 결과를 이미지·동영상·기타로 나눠 보고, 용량 큰 순·작은 순으로 정렬할 수 있습니다.
- 결과를 한 줄 목록과 작은 썸네일로 보여 줍니다. 썸네일을 누르면 크게 볼 수 있습니다.
- 새로 설치하면 Mac의 다운로드 폴더에 저장합니다. 설정(⌘,)에서 저장 위치를 바꾸거나 되돌릴 수 있습니다. 이미 저장 폴더를 고른 경우 그대로 유지합니다.
- 페이지 안에 삽입된 동영상 플레이어(Padlet 등)도 분석합니다.

기존 사용자는 앱의 업데이트 확인으로 설치할 수 있습니다. 신규 설치는 DMG에서 Applications 폴더로 앱을 옮겨 주세요.
