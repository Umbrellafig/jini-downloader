# 지니 다운로더 1.4.0

- 일반 웹페이지의 상품 사진을 찾는 **웹페이지 이미지 찾기…** 추가
- 페이지를 열고 스크롤한 뒤 로드된 이미지 최대 200개를 가져와 선택 저장
- 상품 이미지의 이름·해상도·예상 용량 및 미리보기 제공
- 서버가 돌려준 이미지 파일명에 맞춰 형식 표시 개선
- 사진 엔진이 지원하지 않는 페이지에서 이미지 탐색 방법 안내

알고몬 상품 목록에서 이미지 11개 추출 및 1개 저장을 확인했습니다. 상품 썸네일은 원본보다 작을 수 있으며, 사이트별 보호·로그인 요구에 따라 동작이 달라질 수 있습니다.

Apple Silicon(M1 이상), macOS 26 이상용입니다. Developer ID 서명 및 Apple 공증을 적용합니다.
1.3.0 사용자는 응용 프로그램 폴더에서 앱을 실행한 뒤 **업데이트 확인…**으로 설치할 수 있습니다.
