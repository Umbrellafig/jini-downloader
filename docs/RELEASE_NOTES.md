## 다운로드

일반 사용자는 아래 Assets의 **JiniDownloader-macOS-arm64.zip**을 받으세요. 이 파일에는 앱만 들어 있습니다. GitHub가 별도로 표시하는 Source code는 개발용 소스입니다.

- Apple Silicon(M1 이상), macOS 26 이상
- 첫 실행 시 앱에서 필수 도구 설치: 약 155MB, 인터넷 연결 필요
- 앱은 로컬 임시 서명만 적용되어 Apple의 개발자 확인 경고가 나올 수 있습니다. 출처를 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기에서 해당 앱을 허용할 수 있습니다.
- SHA256SUMS.txt로 ZIP의 체크섬을 확인할 수 있습니다.

미리보기에서 파일 이름·품질·용량을 확인하고 필요한 항목만 선택하세요. 업로드 원본 제공을 보장하지 않으며, 사이트가 제공하는 스트림을 추가 압축 없이 저장합니다.

업데이트 내용은 저장소의 CHANGELOG.md, 설치 도구와 라이선스는 docs/ENGINES.md를 확인해 주세요.
