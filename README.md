## 내 Mac에서도 사용할 수 있나요?

화면 왼쪽 위 ** → 이 Mac에 관하여**에서 확인해 주세요.

| 확인할 항목 | 사용할 수 있는 환경 |
| --- | --- |
| 칩 | Apple M1, M2, M3, M4 등 **M1 이후의 Apple 칩** |
| macOS | **26 이상** |
| 인터넷 | 앱 설치와 파일 다운로드에 필요해요. |

Intel 칩을 사용하는 Mac과 Windows는 현재 지원하지 않아요.

## 처음 설치하나요?

### 1. 설치 파일을 열어요

위 **Mac용 지니 다운로더 다운로드** 버튼을 누르세요. GitHub 로그인은 필요 없어요.
다운로드한 **JiniDownloader-macOS-arm64.dmg**를 더블클릭하면 설치 디스크가 열려요.

### 2. 앱을 Applications 폴더로 드래그해요

설치 창의 **JiniDownloader.app** 아이콘을 **Applications** 폴더 아이콘으로 옮기세요. Applications는 Mac의 **응용 프로그램** 폴더예요.

> [!IMPORTANT]
> 설치 디스크 안의 앱을 바로 실행하지 말고, 먼저 Applications로 옮겨 주세요. 잘못된 위치에서 실행하면 앱이 한글로 설치 방법을 안내해요.

기존 앱이 있다면 종료한 뒤 Finder의 교체 안내를 확인해 주세요. 다운로드한 사진·영상은 앱 교체로 지워지지 않아요.

### 3. 응용 프로그램 폴더에서 실행해요

Finder에서 **⇧⌘A**(Shift + Command + A)를 눌러 응용 프로그램 폴더를 연 뒤 지니 다운로더를 실행하세요. 처음에 인터넷에서 받은 앱을 열겠냐고 물으면 **열기**를 선택하세요.

설치 후 Finder에서 ‘지니 다운로더 설치’ 디스크를 추출해도 돼요. 앱과 DMG는 Apple 개발자 서명과 공증을 적용해 배포해요.

### 4. 처음 한 번, 필수 도구를 설치해요

앱에서 **필수 도구 설치**를 누르고 완료될 때까지 기다려 주세요.

동영상과 사진을 내려받는 데 필요한 도구를 준비하는 과정이에요. 약 **155MB**를 추가로 내려받으며, 인터넷 속도에 따라 시간이 걸릴 수 있어요. 별도의 프로그램을 직접 찾아 설치할 필요는 없어요.

설치가 끝났다면 준비 완료예요!

## 파일을 다운로드해 볼까요?

**링크 붙여넣기 → 미리보기 → 파일 선택 → 다운로드** 순서로 사용해요.

| 순서 | 이렇게 해 주세요 |
| --- | --- |
| **① 링크 넣기** | 웹브라우저에서 동영상이나 사진 게시물의 주소를 복사한 뒤 앱에서 **붙여넣기**를 누르세요. 여러 주소는 한 줄에 하나씩 넣어 주세요. |
| **② 미리보기 확인** | **분석하기**을 누르세요. 제목·썸네일·화질·파일 형식·예상 용량을 보고 원하는 파일이 맞는지 확인해요. |
| **③ 받을 파일 고르기** | 원하는 항목에 체크하세요. 동영상은 저장 품질 메뉴에서 화질을 고를 수 있어요. |
| **④ 저장 위치 정하기** | 폴더 경로 옆의 **변경**을 누르면 저장할 폴더를 고를 수 있어요. 처음에는 **다운로드 → JiniDownloader** 폴더에 저장돼요. |
| **⑤ 다운로드 시작** | **선택 다운로드**를 누르세요. 진행바에서 받은 양·속도·남은 시간을 확인할 수 있어요. |
| **⑥ 저장한 파일 열기** | **저장 완료**가 표시되면 **Finder에서 보기**를 누르세요. 저장 폴더 전체는 **폴더 열기**로 확인할 수 있어요. |

> 영상과 소리를 따로 내려받은 뒤 하나로 합치는 경우가 있어요. 진행바가 100%여도 잠시 기다려 주세요. **‘저장 완료’가 표시되면 파일을 사용할 수 있어요.**

## 사진과 동영상을 한 번에 찾기

**1.5.0부터 링크를 넣고 ‘분석하기’만 누르면 돼요.** 동영상과 웹페이지 이미지를 함께 찾아 같은 목록에 보여 줘요. 종류나 탐색 방식을 따로 고르지 않아도 돼요.

- **선택 다운로드**: 체크한 파일만 받아요.
- **전체 다운로드**: 현재 분석된 목록에서 아직 받지 않은 파일을 모두 받아요.

분석 중에도 항목을 체크할 수 있어요. 파일을 더 찾고 이름·용량 확인이 끝나면 다운로드 버튼이 활성화돼요.

웹페이지에서 로드된 이미지와 직접 재생 주소, 지원되는 사진 게시물 및 동영상 정보를 확인해요. 모든 페이지·동영상을 보장하지는 않으며, 로그인이나 사이트 확인이 필요하면 파일을 찾지 못할 수 있어요. 현재 브라우저의 로그인 정보는 가져오지 않아요.

웹페이지 파일과 사진 게시물은 각각 최대 200개를 확인해요. 전체 다운로드는 웹사이트 전체가 아닌 **결과 목록 전체**를 뜻해요. 로고와 작은 상품 썸네일도 포함될 수 있고, 업로드 원본보다 작을 수 있어요.

## 앱을 최신 버전으로 유지하기

매번 웹사이트에서 다시 받을 필요 없이 **앱 안에서 업데이트**할 수 있어요.

1. **응용 프로그램 폴더에 있는 지니 다운로더**를 실행하세요.
2. 앱 왼쪽 아래의 **업데이트 확인…**을 누르세요. Mac 상단의 앱 메뉴에서도 찾을 수 있어요.
3. 새 버전이 있으면 업데이트 창의 안내에 따라 내려받고 **설치 및 재시작**을 선택하세요.

**자동으로 업데이트 확인**을 켜 두면 새 버전이 있는지 주기적으로 확인해요. 실제 설치는 사용자가 선택해요. 분석·다운로드·필수 도구 설치가 진행 중이라면 먼저 끝난 뒤 업데이트해 주세요.

저장해 둔 동영상·사진과 저장 폴더 설정은 앱 업데이트로 삭제되지 않아요.

> **1.2.0을 사용하고 있나요?** 이 버전에는 업데이트 기능이 없어요. 위 다운로드 링크에서 최신 앱을 한 번 받아 기존 앱을 종료하고 교체해 주세요. 그다음부터 앱 안에서 업데이트할 수 있어요.

## 궁금한 점이 있나요?

자세히 보고 싶은 질문을 눌러 펼쳐 보세요.

<details>
<summary><strong>‘다운로드한 위치에서는 업데이트할 수 없다’는 영어 안내가 나와요.</strong></summary>

`can’t be updated if it’s running from the location it was downloaded to`는 앱을 실행한 위치 때문에 업데이트할 수 없다는 뜻이에요. Apple 인증 실패를 뜻하는 메시지는 아니에요.

1. 지니 다운로더를 **⌘Q**로 완전히 종료하세요.
2. `JiniDownloader.app`을 **응용 프로그램(Applications)** 폴더로 옮기세요.
3. **응용 프로그램 폴더 안에 있는 앱**을 다시 실행하세요.
4. **업데이트 확인…**을 눌러 주세요.

옮긴 뒤에도 계속 나타나면 앱을 종료하고 Finder에서 응용 프로그램 폴더의 앱을 직접 열어 주세요. 다운로드 폴더의 예전 앱을 다시 실행하지 않았는지 확인해 주세요.

</details>

<details>
<summary><strong>유튜브 영상도 원본 화질로 저장되나요?</strong></summary>

지니 다운로더는 **사이트가 제공하고 앱이 접근할 수 있는 화질 중에서 선택한 영상**을 저장해요. 저장할 때 앱이 영상을 다시 압축해 화질을 낮추지는 않아요.

다만 유튜브는 업로드된 영상을 자체적으로 변환해서 제공해요. 따라서 최고 화질을 선택하더라도 **업로더가 처음 올린 원본 파일 자체와 같다는 뜻은 아니에요.** 다운로드 전에 품질 메뉴에서 해상도와 제공되는 형식을 확인해 주세요.

</details>

<details>
<summary><strong>용량에 ‘약’이 붙거나 남은 시간이 안 보여요.</strong></summary>

사이트에서 정확한 파일 크기를 알려주지 않으면 예상 용량에는 **‘약’**, 크기를 알 수 없으면 **‘용량 정보 없음’**이 표시돼요.

다운로드 중에도 전체 크기를 모르면 정확한 퍼센트나 남은 시간을 표시하기 어려워요. 이때는 받은 용량과 속도를 확인해 주세요. 다운로드가 끝나면 실제 저장된 용량을 확인할 수 있어요.

</details>

<details>
<summary><strong>링크를 넣었는데 분석이나 다운로드가 안 돼요.</strong></summary>

먼저 브라우저에서 해당 링크가 열리는지 확인하고, 앱에서 **분석하기** 또는 **분석하기**을 눌러 주세요. 사이트에서 제공하는 화질 목록이 바뀌었을 수도 있어요.

모든 사이트와 파일을 지원하는 것은 아니에요. 로그인이 필요하거나 사이트가 자동 다운로드를 차단하는 경우, 삭제된 콘텐츠, 복사 방지가 적용된 콘텐츠는 받을 수 없을 수 있어요. 진행 중인 라이브 방송과 재생목록 전체 다운로드도 지원하지 않아요.

계속 실패한다면 아래의 **문제 알려주기**로 앱에 표시된 오류를 보내 주세요.

</details>

<details>
<summary><strong>사진이나 썸네일이 일부만 보여요.</strong></summary>

사진 게시물은 한 번에 최대 **200개 항목**을 미리 보여 줘요. 사이트가 미리보기 정보를 제공하지 않거나 이미지가 너무 크면 썸네일 대신 아이콘이 표시될 수 있어요.

</details>

<details>
<summary><strong>다운로드를 취소하면 나중에 이어받을 수 있나요?</strong></summary>

현재는 중간부터 이어받기를 지원하지 않아요. **취소**를 누르면 현재 작업의 임시 파일을 정리하며, 다시 받을 때는 처음부터 시작해요.

</details>

<details>
<summary><strong>앱이 열리지 않거나 개발자를 확인할 수 없다고 나와요.</strong></summary>

이 페이지 위쪽의 다운로드 링크로 **최신 앱**을 받고, 기존 앱을 종료한 뒤 응용 프로그램 폴더의 앱을 교체해 주세요. 최신 배포 앱은 Apple 서명과 공증을 거쳤어요.

그래도 열리지 않는다면 경고 문구, 앱 버전, macOS 버전을 함께 알려 주세요. [Apple의 앱 실행 경고 안내](https://support.apple.com/en-gb/102445)도 참고할 수 있어요.

</details>

<details>
<summary><strong>제가 다운로드한 파일이나 링크를 수집하나요?</strong></summary>

다운로드한 콘텐츠를 개발자의 서버에 보내거나 광고·분석 목적으로 수집하는 기능은 없어요.

파일을 받을 때는 해당 사이트에, 필수 도구 설치와 앱 업데이트 때는 해당 배포 서버에 연결해요. 파일 옆에 생성되는 `.download.txt`는 출처와 저장 정보를 적은 기록 파일이에요.

오류 화면이나 기록을 공개할 때는 개인적인 링크 등 공유하고 싶지 않은 정보를 가려 주세요.

</details>

```bash

```

로컬 ZIP은 `dist/JiniDownloader-macOS-arm64.zip`에 생성돼요. 로컬 빌드와 Apple 공증을 완료한 정식 배포판은 달라요. 공개 배포는 위 릴리스 문서를 참고해 주세요.

외부 다운로드 도구는 앱 ZIP에 포함하지 않으며, 첫 실행 시 고정된 버전과 SHA-256을 검증해 설치해요. yt-dlp·gallery-dl·Deno는 각 프로젝트의 GitHub 배포처에서, FFmpeg·FFprobe는 Martin Riedl의 macOS 빌드 배포처에서 가져와요. FFmpeg 프로젝트가 직접 제공하는 바이너리는 아니에요.

앱 업데이트는 [Sparkle](https://sparkle-project.org/)을 사용해요. 업데이트 파일의 Ed25519 서명을 검증하며, Sparkle 라이선스는 앱 안에 포함돼요. GitHub Actions에서 서명된 새 릴리스를 빌드하려면 릴리스 문서에 나온 인증 정보를 별도로 설정해야 해요.

| 다운로드 도구 | `~/Library/Application Support/JiniDownloader/Engines` |
