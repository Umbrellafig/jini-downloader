# 지니 다운로더 · Jini Downloader

**다운로드 전에 파일을 확인하고, 원하는 품질로 저장하는 Mac 앱.**

URL을 분석해 이름·썸네일·포맷·해상도·예상 용량을 확인한 다음, 필요한 파일만 골라 저장합니다. 다운로드 중에는 진행바로 퍼센트·속도·남은 시간을 볼 수 있습니다.

## 앱 다운로드

### [⬇️ Mac 앱만 다운로드](https://github.com/Umbrellafig/jini-downloader/releases/latest/download/JiniDownloader-macOS-arm64.zip)

**Apple Silicon(M1 이상) · macOS 26 이상**

이 버튼은 소스 코드가 아닌 **JiniDownloader.app만 담은 ZIP**을 내려받습니다. 업데이트 후에도 같은 버튼으로 최신 정식 버전을 받을 수 있습니다.

[모든 버전·변경 사항](https://github.com/Umbrellafig/jini-downloader/releases) · [SHA-256 체크섬](https://github.com/Umbrellafig/jini-downloader/releases/latest/download/SHA256SUMS.txt) · [자세한 사용법](docs/USAGE.md)

## 처음 실행할 때

1. ZIP을 압축 해제하고 `JiniDownloader.app`을 응용 프로그램 폴더로 옮깁니다.
2. 앱을 실행합니다. 1.3.0부터 Developer ID 서명과 Apple 공증을 적용했습니다. 최초 실행 시 인터넷에서 내려받은 앱인지 묻는 일반 확인 창이 나올 수 있습니다.
3. 앱의 **필수 도구 설치**를 누릅니다. 약 155MB의 다운로드 엔진을 각 배포처에서 한 번 내려받습니다. 인터넷 연결이 필요하고, 관리자 암호는 필요하지 않습니다.
4. 설치가 완료되면 URL을 입력하고 **미리보기 분석**을 누릅니다.
5. 받을 파일·저장 품질·저장 폴더를 선택하고 **선택한 파일 다운로드**를 누릅니다.

앱은 설치 파일의 고정된 버전과 SHA-256을 확인합니다. 엔진 바이너리는 이 저장소나 앱 ZIP에 포함하지 않습니다. yt-dlp·gallery-dl·Deno는 각 프로젝트의 GitHub 배포처에서, FFmpeg·FFprobe는 **Martin Riedl의 macOS 빌드 배포처**에서 가져옵니다. FFmpeg 프로젝트가 직접 배포하는 바이너리라는 의미는 아닙니다. [도구와 라이선스 안내](docs/ENGINES.md)

### macOS에서 실행이 차단될 때

1.3.0부터는 Apple 공증을 거친 앱을 배포합니다. 예전 1.2.0 또는 개인용 빌드에서 개발자를 확인할 수 없다는 경고가 나타나면 위 버튼에서 최신 버전을 받아 교체하세요. 최신 버전에서도 차단된다면 정확한 경고 문구와 macOS 버전을 이슈에 알려주세요. [Apple 공식 안내](https://support.apple.com/en-gb/102445)

## ‘최고 품질’과 ‘업로드 원본’은 다릅니다

앱은 분석 시 엔진이 접근 가능한 포맷 중 권장하는 것을 기본으로 선택합니다. 다운로드한 영상에 앱이 추가로 압축을 가하지는 않습니다.

그러나 **유튜브 같은 서비스가 재생용으로 제공하는 영상은 업로드 원본 파일 자체가 아닙니다.** ‘최고 품질’은 원본 파일과 바이트 단위로 동일하다는 보장이 아닙니다. 같은 해상도라도 AV1·VP9·H.264 등 서로 다른 코덱이 있을 수 있으며 파일 크기만으로 화질을 비교할 수 없습니다.

예상 용량의 **‘약’은 추정값**입니다. 서버에서 크기를 알려주지 않으면 ‘용량 정보 없음’으로 표시하고, 다운로드 완료 후 실제 크기를 표시합니다. 확인되지 않은 정보를 만들어 보여주지 않습니다.

## 지원 범위와 제한

- 본인이 만든 콘텐츠 또는 다운로드 권한이 있는 콘텐츠에 사용하세요. 각 사이트의 약관과 적용 법률을 준수해야 합니다.
- 모든 웹사이트를 지원하거나 모든 사이트의 업로드 원본을 제공한다고 보장하지 않습니다.
- DRM 우회, 로그인·쿠키 가져오기, 진행 중인 라이브, 재생목록 전체 다운로드는 지원하지 않습니다.
- 봇 차단이나 사이트 변경 때문에 분석·다운로드가 실패할 수 있습니다.
- 일부 파일은 썸네일·크기·해상도 사전 정보가 없을 수 있습니다.
- 취소하면 현재 작업의 임시 파일을 정리합니다. 중간 지점에서 다운로드 재개는 지원하지 않습니다.
- 현재 제공하는 실행 파일은 Apple Silicon 및 macOS 26 이상용입니다. Intel Mac은 지원하지 않습니다.
- 1.3.0부터 앱 안에서 업데이트를 확인하고 설치할 수 있습니다. 1.2.0 사용자는 이번 버전을 한 번 직접 설치해야 합니다. 엔진 버전은 앱에 포함된 설치 목록으로 관리합니다.

## 개인정보와 저장 위치

사용자 콘텐츠를 개발자의 서버로 업로드하거나 분석·광고용으로 수집하는 기능은 없습니다. URL을 분석·다운로드할 때 대상 사이트와 미디어 서버에 접속하고, 최초 도구 설치 때 명시된 배포처에 접속합니다.

- 기본 미디어 폴더: `~/Downloads/JiniDownloader`
- 엔진 설치 폴더: `~/Library/Application Support/JiniDownloader/Engines`
- 완료 파일 옆의 `.download.txt`: 출처·선택 포맷·실제 용량 기록

로그나 기록 파일에는 입력 URL이 포함될 수 있습니다. 오류를 공유할 때 개인 URL이나 서명된 링크 등 공개하고 싶지 않은 정보를 먼저 지워 주세요.

소스는 SwiftUI로 작성했습니다. Apple Command Line Tools가 있는 Mac에서:

## 앱 안에서 업데이트 (1.3.0부터)

왼쪽 아래 **업데이트 확인…** 또는 앱 메뉴의 같은 항목을 누르면 최신 버전과 설치 여부를 확인할 수 있습니다. 새 버전은 Sparkle 업데이트 창에서 다운로드 진행률을 확인하고 **설치 및 재시작**으로 적용합니다. **자동으로 업데이트 확인**을 켜면 주기적으로 확인합니다. 설치는 사용자가 선택하며 미디어 다운로드·분석·도구 설치 중에는 업데이트 확인을 미룹니다.

1.2.0에는 업데이트 기능이 없으므로 업데이트를 지원하는 첫 버전은 한 번 직접 설치해야 합니다. 앱을 압축 해제한 뒤 응용 프로그램 폴더에 옮겨 사용하세요. 저장된 미디어·저장 폴더 설정·다운로드 도구는 앱 밖에 보관되어 앱 업데이트로 삭제되지 않습니다.

업데이트 ZIP은 Ed25519 서명을 검증한 뒤 설치합니다. 1.3.0 배포 앱은 Developer ID 서명과 Apple 공증을 완료했으며, 공증 확인서를 앱에 첨부했습니다.

자동 업데이트 기능은 [Sparkle](https://sparkle-project.org/)을 사용하며, 라이선스는 앱 안에 포함됩니다.
